# 쉬운 말 문체 가이드 — 담당: 송유진

> 1차 사용자(대전 60대 이상 어르신)가 읽는 모든 화면 문구·AI 풀이 문장에 적용한다.
> 기존 원칙(`docs/03-AI-설계.md` 「프롬프트」)을 구체적인 규칙·표로 풀어썼다.

## 핵심 규칙 4가지

1. **한 문장 40자 이내.** 두 가지 이상 말하지 않는다 — 안 되면 문장을 나눈다.
2. **한자어는 풀어 쓴다.** 뜻을 아는 사람도 익숙하지 않은 단어는 일상어로 바꾼다
   (아래 「바꿔 쓰기 표」).
3. **숫자·날짜는 원문 그대로.** "48,200원", "2026-10-31"처럼 고치지 않는다 — 돈·기한은
   틀리면 안 되는 값이라 AI가 다시 쓰다 실수하는 것보다 원문을 그대로 보여주는 게 안전하다.
4. **동사로 끝낸다.** "납부 안내" 보다 "내세요"/"내기" — 할 일이 바로 느껴지게.

## 바꿔 쓰기 표

| 한자어·공문체 | 쉬운 말 |
|---|---|
| 납부 | 내기 / 내다 |
| 납부기한 | 내야 하는 날 / 기한 |
| 체납 | 못 낸 돈 |
| 연체금·가산세 | (돈을) 더 내야 하는 것 |
| ~에 따라 | (가능하면 생략) |
| ~경과 시 | ~이 지나면 |
| 제출 | 내다 |
| 발급 | 받기 |
| 유예 | 미루기 |
| ~의 경우 | ~이면 |
| 환급 | 돌려받기 |

규칙은 끝이 없다 — 새 표현이 필요하면 이 표에 바로 추가한다.

## 적용 현황 점검 (2026-10-18)

현재 화면·샘플 문구를 이 가이드로 점검한 결과, 이미 대체로 맞는다:

- `web/index.html` 문구("손주 모드", "가족에게 보내기", "챙길 서류") — 동사형·쉬운 말 ✅
- `backend/app/sample.py`의 `plain`(쉬운 말 요약 3줄) — "~내야 해요", "~되면 돼요" 체 ✅
- `backend/app/agent.py`의 `_title_for()`(할 일 카드 제목: "{도장종류} 금액 내기",
  "신청하기", "{문서종류} 제출하기") — 이 가이드의 바꿔 쓰기 표와 일치 ✅

**남은 일**: 실제 비전 LLM이 뽑아내는 `document_text`(원문)에서 `plain`/근거 문장을 만드는
단계(rag 연동 전까지는 비어 있음, `docs/03-AI-설계.md` 참고)가 채워지면, 그 단계의 프롬프트에
이 문서를 직접 참조시킨다 — 지금은 사람이 쓰는 참고 문서지만, 나중엔 프롬프트 재료가 된다.

## 체크리스트 (새 문구를 화면에 추가할 때)

- [ ] 40자 안에 들어가는가
- [ ] 한자어를 썼다면 바꿔 쓰기 표에 없는 새 표현인가 — 있으면 표에 추가
- [ ] 숫자·날짜를 AI가 다시 쓰지 않고 원문 그대로 옮겼는가
- [ ] 동사로 끝나는가(안내문이 아니라 할 일처럼 읽히는가)
