# AI 설계

> 과제 목표: 프롬프트·RAG·메모리 등을 **목적에 맞게 적용한 근거**를 설명할 수 있어야 한다.
> 무엇을 썼는지보다 **왜** 를 적는다.

## 프롬프트

- **출력은 JSON 하나로 고정한다**(`backend/app/schema.py` 의 `Decoded`).
  왜: 화면이 3색 표시와 할 일 카드를 그리려면 금액·기한·좌표가 필드로 와야 한다. 자유 문장은 정규식으로 되읽다가 틀린다.
- **근거 없는 문장은 내지 않는다.** 풀이 문장마다 원문 인용(`quote`)을 붙이게 하고, 인용이 없는 문장은 백엔드가 버린다.
  왜: 고지서 풀이가 틀리면 사용자가 돈을 잃는다. 사용자가 원문과 대조할 수 있어야 믿을 수 있다.
- **쉬운 말 규칙**: 한 문장 40자 이내, 한자어는 풀어 쓰기(「납부기한 경과 시」 → 「기한을 넘기면」), 숫자·날짜는 원문 그대로.

## Agent 구조

`backend/app/agent.py` 의 `decode()` 가 단계를 차례로 부른다. 단계마다 담당자가 다르고, 앞 단계 결과만 보고 다음 단계를 고른다.
아래 순서가 **지금 코드 순서**다(2026-10-27). 개인정보를 가린 글자만 뒤 단계로 넘기려고 판별을 추출·가림 뒤에 둔다.

| 단계 | 하는 일 | 모듈 · 담당 | 다음 단계를 고르는 기준 | 지금 |
|---|---|---|---|---|
| ① 추출 | 글자와 금액·기한·서류 표시(좌표) | `extract.py` · 황지영 | 글자가 비면 샘플로 끝낸다 | ✅ 비전 LLM(Gemini) |
| ② 가림 | 주민번호·계좌번호 | `redact.py` · 이정관 | 여기서부터 가린 글자만 쓴다 | ✅ |
| ③ 근거 | 인용된 법령 조문 찾기 | `rag.py` · 김기훈 | 원문 인용(`quote`)이 없는 풀이는 버린다 | △ 조문 번호 인용만 |
| ④ 판별 | 고지서·가정통신문·안내문·신청서 | `agent.py` · 오주현 | 신청서면 `reply_needed` 를 켠다 | △ 낱말로만(LLM 판별 자리) |
| ⑤ 할 일 | 표시를 할 일 카드로(금액·기한 짝짓기) | `agent.py` · 오주현 | 기한이 있으면 알림 도구를 부른다 | ✅ 규칙 |
| ⑥ 답장 | 회신 문장·준비물 목록 | `agent.py` · 오주현 | — | ✗ `reply_draft` 는 아직 비어 있다 |

도구 호출: 기한 알림(n8n webhook — 실제 해독에 기한이 있고 서버에 `N8N_WEBHOOK_URL` 이 있을 때, 응답을 보낸 뒤 백그라운드로).
손주 모드 링크는 Agent 가 부르는 도구가 아니라 사용자가 [가족에게 보내기]를 누를 때 화면이 `POST /share` 로 만든다.

## RAG

- 지식원: 국가법령정보센터(법령·조문), 정부24 서비스 안내(감면·지원 제도). 고지서가 자주 인용하는 법령부터 모은다 — 국민건강보험법, 지방세법, 초·중등교육법.
- 청크·검색: 조문 하나 = 청크 하나(조문 번호를 메타데이터로). 고지서에서 뽑은 법령명·조문 번호로 먼저 거르고, 그다음 문장 유사도로 고른다.
  왜: 고지서는 「같은 법 제○조」처럼 번호로 인용한다. 번호를 쓰면 유사도 검색만 할 때보다 훨씬 정확하다.
- 지금(2026-10-27): 번호로 거르는 단계까지만 있다 — 고지서에 조문 인용이 없으면 근거가 비고, 화면은 「이 문서에서 법령 근거는 찾지 못했어요」를 보인다. 인용 없이 비슷한 내용을 찾는 유사도 검색은 진짜 임베딩 배관이 필요해 아직이다(`rag.py` 머리말). 조문 원본 = `data/legal/articles.jsonl`(법제처 원문과 대조).

## Memory

쓰지 않는다. 사용자 고지서는 개인정보 덩어리라 저장할수록 위험이 커진다. 사진은 메모리에서만 쓰고 저장하지 않는다. 손주 모드 링크는 해독 결과(사진 아님)만 SQLite 에 30일 담고 지운다(만료분은 저장·조회 때 정리, 최대 1000개). 화면의 「다 했어요」 기록은 서버가 아니라 그 핸드폰 브라우저(localStorage)에만 남고 기한 30일이 지나면 지운다.

## 실패했을 때

- 키가 없거나 호출이 실패하면: 샘플 해독 결과(`backend/app/sample.py`, 가짜 고지서)를 돌려주고 화면 위에 「샘플 모드 — 실제 고지서 풀이가 아니에요」 배너를 띄운다.
- 금액·날짜가 LLM 값과 OCR 숫자에서 어긋나면: 그 칸을 「직접 확인 필요」로 표시하고 할 일 카드를 만들지 않는다 — **계획만, 아직 없다**(OCR 이중 확인 배관이 없다).
- 요청이 너무 많으면(IP 당 1분 10번): 429 와 함께 몇 초 뒤에 다시 올리면 되는지(`Retry-After`) 알려 주고, 화면은 「N초 뒤에 다시 올려 주세요」를 보인다.
