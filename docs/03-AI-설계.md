# AI 설계

> 과제 목표: 프롬프트·RAG·메모리 등을 **목적에 맞게 적용한 근거**를 설명할 수 있어야 한다.
> 무엇을 썼는지보다 **왜** 를 적는다.

## 프롬프트

- **출력은 JSON 하나로 고정한다**(`backend/app/schema.py` 의 `Decoded`).
  왜: 화면이 3색 표시와 할 일 카드를 그리려면 금액·기한·좌표가 필드로 와야 한다. 자유 문장은 정규식으로 되읽다가 틀린다.
- **좌표는 `box_2d`([위, 왼쪽, 아래, 오른쪽], 0~1000)로 받는다.**
  왜: Gemini 가 학습한 좌표 형식이다. 0~1 비율을 시키면 0~1000 값을 그대로 돌려줘 상자가 사진 밖에 그려졌다(10-23 실측).
- **근거 없는 문장은 내지 않는다.** 풀이 문장마다 법 조문 원문(`quote`)을 붙이고, 원문이 없는 풀이는 백엔드가 버린다.
  왜: 고지서 풀이가 틀리면 사용자가 돈을 잃는다. 사용자가 원문과 대조할 수 있어야 믿을 수 있다.
- **답장 초안은 고지서에 적힌 사실만 옮긴다.** 사정을 적을 자리는 「[여기에 사정을 적어 주세요]」 빈칸으로 둔다(`backend/app/reply.py`).
  왜: 의견 제출서에 지어낸 사정이 들어가면 그대로 행정청에 나간다.
- **쉬운 말 규칙**: 한 문장 40자 이내, 한자어는 풀어 쓰기(「납부기한 경과 시」 → 「기한을 넘기면」), 숫자·날짜는 원문 그대로([쉬운 말 가이드](06-쉬운말-가이드.md)).

## Agent 구조

`backend/app/agent.py` 의 `decode()` 가 다섯 단계를 차례로 부른다. 단계마다 담당자가 다르고, 앞 단계 결과를 보고 다음 단계를 고른다.
개인정보를 가린 글자만 뒤 단계로 넘기려고, 판별을 추출·가림 뒤에 둔다.

| 단계 | 하는 일 | 모듈 · 담당 | 다음 단계를 고르는 기준 |
|---|---|---|---|
| ① 추출 | 비전 LLM(Gemini)이 글자와 금액·기한·서류 표시(좌표)를 뽑는다 | `extract.py` · 황지영 | 글자가 비면 샘플 모드로 끝낸다. 금액·날짜는 같은 응답의 본문 글자와 다시 맞춰 보고, 어긋나면 그 표시를 버린다 |
| ② 가림 | 주민등록번호·계좌번호·전화번호를 가린다 | `redact.py` · 이정관 | 여기서부터 가린 글자만 쓴다 |
| ③ 근거 | 고지서가 인용한 「○○법 제○조」의 원문을 찾는다 | `rag.py` · 김기훈 | 원문(`quote`)이 없는 풀이는 버린다 |
| ④ 판별 | 과태료·고지서·가정통신문·신청서·안내문 중 무엇인지 고른다 | `agent.py` · 오주현 | 과태료면 답장 초안(⑥)을 부른다. 신청서·과태료면 `reply_needed` 를 켠다 |
| ⑤ 할 일 | 표시를 할 일 카드로 묶는다(금액·기한 짝짓기, 같은 카드는 한 장) | `agent.py` · 오주현 | 기한이 있으면 알림 도구를 부른다 |
| ⑥ 답장 초안 | 과태료 고지서면 의견 제출서 초안 + 감경 근거 조문 3개 | `reply.py` · 오주현 | LLM 이 실패하면 빈칸 양식을 준다 |

**도구 호출**
- **기한 알림**(`notify.py`): 할 일마다 기한 사흘 전·당일 오전 9시 알림을 만들어 응답의 `alerts` 에 싣는다. 화면은 카카오톡 말풍선으로 보여 준다. 카카오톡과는 연결하지 않은 가상 발송이다. 서버에 `N8N_WEBHOOK_URL` 이 있으면 같은 할 일을 n8n 에 넘긴다(응답 뒤 백그라운드). 지난 기한은 알리지 않는다.
- **손주 모드 링크**는 Agent 가 부르는 도구가 아니다. 사용자가 [가족에게 보내기]를 누르면 화면이 `POST /share` 로 만든다.

## RAG

- **지식원**: 국가법령정보센터(법제처) 조문 10개, `data/legal/articles.jsonl`. 법제처 Open API 원문과 글자 단위로 대조했다(`python -m scripts.verify_legal_articles` → 10/10 `[OK]`, 2026-11-01).

  | 법령 | 조문 | 고지서에서 쓰이는 곳 |
  |---|---|---|
  | 국민건강보험법 | 제80조 | 건강보험료 연체금 |
  | 지방세기본법 | 제55조 | 지방세(자동차세 등) 3% 가산세 |
  | 지방세법 | 제115조 | 재산세 납기 |
  | 국민연금법 | 제97조 | 국민연금료 연체금 |
  | 전기사업법 | 제51조 | 전력산업기반기금 부담금 가산금 |
  | 도로교통법 | 제164조 | 범칙금 20% 가산 |
  | 질서위반행위규제법 | 제16조·제18조·제24조 | 과태료 의견 제출·자진납부 감경·3% 가산금 |
  | 질서위반행위규제법 시행령 | 제5조 | 감경 범위(20%) |

- **청크·검색**: 조문 하나 = 청크 하나(법령명·조문 번호를 메타데이터로). 고지서 글자에서 「○○법 제○조(의N)」를 찾아 **번호로 맞춘다**.
  왜: 고지서는 법을 조문 번호로 적는다. 번호로 맞추면 비슷한 문장을 찾는 것보다 틀린 조문이 붙을 일이 없다. 「제80조의2」를 「제80조」로 뭉뚱그리지 않는다.
- **인용이 없으면 근거를 붙이지 않는다.** 화면은 「이 고지서에서 관련 법 조항은 찾지 못했어요」를 보인다. 비슷한 문장으로 찾는 유사도 검색은 쓰지 않는다 — 틀린 근거가 근거 없음보다 위험하다.
- **과태료 감경 근거**: 과태료 고지서는 인용이 없어도 의견 제출·감경 조문 3개(법 제16조·제18조, 시행령 제5조)를 붙인다. 답장 초안이 기대는 법이라서다.

## Memory

장기 기억은 쓰지 않는다. 사용자 고지서는 개인정보 덩어리라 저장할수록 위험이 커진다.

- 사진은 메모리에서만 쓰고 저장하지 않는다.
- 손주 모드 링크는 해독 결과(사진 아님)만 SQLite 에 30일 담는다. 만료분은 저장·조회 때 지우고, 최대 1000개다.
- 「다 했어요」 기록은 그 핸드폰 브라우저(localStorage)에 남고, 기한 30일이 지나면 지운다. 공유한 고지서의 기록은 그 링크에도 함께 적어(최대 50개) 가족 화면이 20초마다 읽는다. 링크가 만료되면 같이 지운다.

## 실패했을 때

- 키가 없거나 추출이 실패하면: 샘플 해독 결과(`backend/app/sample.py`, 가짜 고지서)를 돌려주고 「샘플 모드 — 실제 고지서 풀이가 아니에요」 배너를 띄운다.
- 금액·날짜가 본문 글자와 어긋나면: 그 표시를 그리지 않는다. 틀린 색칠보다 빈칸이 안전하다. 같은 AI 가 읽은 글자와 맞추는 것이라 사진을 다른 방법으로 다시 읽지는 않는다 — 돈·날짜는 받은 고지서와 직접 확인하라고 「AI 풀이 — 원문을 함께 확인하세요」를 늘 띄운다.
- 답장 초안 LLM 이 실패하면: 빈칸 양식(`reply.TEMPLATE`)을 준다.
- 근거 저장소(Chroma)가 실패하면: 근거 없이 나머지를 끝까지 보여 준다.
- 요청이 너무 많으면(IP 당 1분 10번): 429 와 함께 몇 초 뒤에 다시 올리면 되는지(`Retry-After`) 알려 주고, 화면은 「N초 뒤에 다시 올려 주세요」를 보인다.
