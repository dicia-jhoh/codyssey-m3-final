# 발표 자료

> 미션 산출물 5. 필수로 담을 것 세 가지 — ① 문제 정의 및 해결 과정 ② AI 활용 방식 및 기술적 의사결정 근거 ③ 사용자 피드백 및 개선 사항.

발표는 **6분 영상 한 편**이다(장면 9개, 화면 + 내레이션 + 자막). 영상 원본은 팀 발표 보드(`awesomeboard` 저장소 `boards/ttobak-m3`)에 있다.
결과 장면의 숫자는 이 저장소의 채점기(`backend/scripts/score_testset.py`)를 배포 서버에 돌린 값이다 — 손으로 계산하지 않는다.

## 기술적 의사결정 — 발표에서 짚는 것

- **요약 대신 할 일**: 원문을 줄이지 않고 원문 위에 긋는다. 어르신이 받은 종이와 화면이 같아야 믿는다.
- **조문 번호로 먼저 맞춘다**(김기훈, [AI 설계 「RAG」](03-AI-설계.md#rag)): 고지서는 법을 번호로 인용한다. 비슷한 문장 검색은 틀린 조문을 붙일 수 있다.
- **금액·날짜를 본문과 다시 맞춘다**(황지영): 틀린 색칠보다 빈칸이 안전하다.
- **PR #9 의 교훈**: 테스트는 모두 통과했지만 실제 사진에서 실패했다(`media_type` 고정). PR #15 부터 실제 사진으로 다시 확인한다 — README 「추출 모듈 이야기」.
- **가린 글자만 뒤로**: 주민등록번호·계좌번호·전화번호를 가린 뒤 근거·화면·공유로 넘긴다.
