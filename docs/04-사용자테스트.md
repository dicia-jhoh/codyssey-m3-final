# 사용자 테스트

> 요건: 실사용자 **5명 이상**에게 제공하고 피드백을 반영한다. 실명 대신 `사용자 N`.

## 테스트 설계
- 담당: 진행 송유진 · 분석 김기훈
- 대상: 팀원 6명의 가족 각 1명 이상(1차 대상 = 60대 이상 어르신). 실명 대신 `사용자 N`.
- 과제(사용자에게 시킬 일): 최근 집에 온 고지서 1장을 직접 찍어 올리고, 화면만 보고 「얼마를·언제까지·무엇을」 해야 하는지 말해 보게 한다.
- 관찰할 것:
  - 도움 없이 사진 올리기까지 걸린 시간, 막힌 곳
  - 사용자가 말한 할 일이 고지서 원문과 맞는지(맞음·틀림·빠짐)
  - 3색 표시와 근거 링크를 실제로 눌러 보는지
  - 「무엇을 언제까지 해야 하는지 알겠다」 5점 척도
- 일정: 1차 = 5주차(기능 시험), 2차 = 6주차(1차 피드백 반영 뒤 재사용)

## 질문지 초안 (진행자가 그대로 읽는 대본)

> 진행자(송유진)가 "관찰할 것"을 실제 질문으로 바꾼 것. 어르신 대상이라 질문도
> `docs/06-쉬운말-가이드.md` 기준(짧은 문장·쉬운 말)으로 쓴다.

**시작 전**
1. "요즘 집에 온 고지서나 안내문 있으세요? 그거 한 장 써볼게요." (사용자가 가진 실물 사용 — 없으면 샘플로 대체하고 기록에 남긴다)
2. "핸드폰으로 사진 찍듯이 여기를 눌러 주세요." (도움 없이 시작 — 진행자는 막힐 때까지 말 안 함)

**사진 올린 뒤 (화면 보여주고)**
3. "이거 보고, 얼마를 내야 하는지 말씀해 주시겠어요?"
4. "언제까지 내야 하는지도요?"
5. "더 챙겨야 할 서류나 할 일이 있을까요?"
6. "여기 색칠된 부분(가리키며) 뭔지 알아보시겠어요?"
7. "아래 '쉬운 말 풀이'나 '원문' 부분, 한번 눌러봐 주시겠어요?" (근거 링크를 실제로 찾아 누르는지 관찰)

**마무리**
8. "방금 화면 보고 뭘 해야 하는지 알겠다, 1점(전혀 모르겠다)부터 5점(확실히 알겠다) 중 몇 점이세요?"
9. "불편하거나 헷갈렸던 부분 있으면 편하게 말씀해 주세요."
10. (손주 모드 시연) "이 결과를 자녀분께 링크로 보내드릴 수 있어요 — 한번 보내볼까요?"

**진행자 기록란(사용자 1명당)**
- 사진 올리기까지 걸린 시간: ___
- 막힌 지점(있다면): ___
- 3번~5번 답이 원문과 맞았는지: 맞음 / 틀림 / 빠짐 — 어느 항목: ___
- 6번(3색 표시) 이해: 예 / 아니오
- 7번(근거 링크) 실제로 눌러봤는지: 예 / 아니오
- 8번 점수(1~5): ___
- 9번 코멘트: ___
