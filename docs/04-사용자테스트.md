# 사용자 테스트

> 요건: 실사용자 **5명 이상**에게 제공하고 피드백을 반영한다. 실명 대신 `사용자 N`.

## 테스트 설계
- 대상: 팀원 5명의 가족 각 1명 이상(1차 대상 = 60대 이상 어르신). 실명 대신 `사용자 N`.
- 과제(사용자에게 시킬 일): 최근 집에 온 공문 1장을 직접 찍어 올리고, 화면만 보고 「얼마를·언제까지·무엇을」 해야 하는지 말해 보게 한다.
- 관찰할 것:
  - 도움 없이 사진 올리기까지 걸린 시간, 막힌 곳
  - 사용자가 말한 할 일이 공문 원문과 맞는지(맞음·틀림·빠짐)
  - 3색 표시와 근거 링크를 실제로 눌러 보는지
  - 「무엇을 언제까지 해야 하는지 알겠다」 5점 척도
- 일정: 1차 = 5주차(기능 시험), 2차 = 6주차(1차 피드백 반영 뒤 재사용)
