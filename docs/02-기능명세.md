## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 응답 시간 | 사진 1장 해독 15초 이내(처리 중 경과 초 표시 — 10초 넘으면 「조금만 더 기다려 주세요」). 측정은 #133 |
| 정확도 | 테스트셋 30장에서 금액·기한·할 일 추출 90% 이상 |
| 개인정보 | 동의 후 수집, 추출 뒤 화면·공유 전 가림, 사진 원본은 처리 후 삭제(동의 시만 보관), 저장소에 올리지 않음 |
| AI 표시 | 모든 풀이 화면에 「AI 풀이 — 원문을 함께 확인하세요」 배지 |
| 접근성 | 큰 글씨(기본 18px 이상), 앱 설치 없이 링크 하나로 연다 |
| 키 없음 | LLM 키가 없거나 호출이 실패해도 화면이 깨지지 않는다 — 샘플 모드 배너로 알린다 |
| 업로드 한도 | 10MB 넘으면 본문을 다 받기 전에 413. 화면은 큰 사진을 미리 줄여 보낸다 |
| 요청 제한 | `/decode` IP 당 1분 10번(`DECODE_PER_MINUTE`) — 넘으면 429 + `Retry-After`(초), 화면은 「N초 뒤에 다시 올려 주세요」 |

## 시스템 아키텍처

```
[모바일 웹 web/] ──사진──▶ [FastAPI backend/]
                              │ agent.py    추출 → 개인정보 가림 → 근거 → 종류 판별 → 할 일 · 답장 필요 여부
                              │      ├ extract.py  비전 LLM (좌표 포함)
                              │      ├ redact.py   주민번호·계좌번호 가림
                              │      └ rag.py      국가법령정보·정부24 (Chroma)
                              ▼
                        Decoded JSON ──▶ 화면: 3색 표시 · 할 일 카드 · 근거 링크
                              │                    │
                              │                    └─ [가족에게 보내기] ──▶ POST /share ──▶ SQLite 30일 ──▶ 손주 모드 링크
                              └─ 기한(실제 해독만) ──▶ [n8n automation/] ──▶ D-3·D-day 알림
```

## 데이터 모델

`backend/app/schema.py` 가 정본이다. 화면과 n8n 은 이 모양만 믿는다.

| 이름 | 필드 | 뜻 |
|---|---|---|
| `Mark` | `kind` · `text` · `value` · `bbox` | 원본 위 표시 하나. `kind` = `money`(빨강)·`deadline`(파랑)·`document`(초록), `bbox` = 사진 대비 비율 `[x, y, w, h]` |
| `Todo` | `title` · `due` · `amount` · `how` | 할 일 카드 한 장 |
| `Basis` | `claim` · `quote` · `law` | 풀이 문장 하나와 그 근거(원문 문장, 법령 조문) |
| `Decoded` | `doc_type` · `title` · `plain` · `marks` · `todos` · `basis` · `reply_needed` · `reply_draft` · `sample` · `ai_notice` | `/decode` 응답 전체. `sample = true` 면 샘플 모드, `ai_notice` = 화면 위 「AI 풀이 — 원문을 함께 확인하세요」 |
