# 기능 요구 명세서 · 시스템 아키텍처

> 미션 산출물 2. 기능은 [기획서](01-기획서.md)의 핵심 기능에서 왔다. 담당은 기획서 역할분담을 따른다.

## 기능 요구사항

| ID | 기능 | 설명 | 우선순위 | 담당 |
|---|---|---|---|---|
| FR-01 | 사진 올리기 | 휴대폰으로 공문을 찍거나 앨범에서 골라 올린다 | Must | 송유영 · 이정관 |
| FR-02 | 개인정보 가림 | 주민등록번호·계좌번호를 **LLM 에 보내기 전에** 가린다 | Must | 이정관 |
| FR-03 | 공문 판별 | 고지서·가정통신문·안내문·신청서 중 무엇인지 고른다 | Must | 오주현 |
| FR-04 | 3색 빨간펜 | 원본 사진 위에 빨강 = 낼 돈, 파랑 = 기한, 초록 = 챙길 서류를 표시한다 | Must | 황지영 · 송유영 |
| FR-05 | 할 일 카드 | 「10.31까지 · 48,200원 · 앱 납부」처럼 할 일 하나를 카드 한 장으로 만든다 | Must | 오주현 · 송유영 |
| FR-06 | 근거 문장 링크 | 풀이 한 줄마다 원문 위치와 법령 조문을 붙인다. 근거가 없는 문장은 내지 않는다 | Must | 김기훈 |
| FR-07 | 손주 모드 | 해독본을 자녀에게 링크로 보낸다 | Should | 송유영 · 이정관 |
| FR-08 | 기한 알림 | 기한 D-3·D-day 에 알림을 보낸다 | Should | 이정관 |
| FR-09 | 답장 초안 | 회신·신청이 필요한 공문이면 제출용 문장과 준비물 목록을 만든다 | Could | 오주현 |

## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 응답 시간 | 사진 1장 해독 15초 이내(처리 중 진행 표시) |
| 정확도 | 테스트셋 30장에서 금액·기한·할 일 추출 90% 이상 |
| 개인정보 | 동의 후 수집, LLM 전송 전 가림, 사진 원본은 처리 후 삭제(동의 시만 보관), 저장소에 올리지 않음 |
| AI 표시 | 모든 풀이 화면에 「AI 풀이 — 원문을 함께 확인하세요」 배지 |
| 접근성 | 큰 글씨(기본 18px 이상), 앱 설치 없이 링크 하나로 연다 |
| 키 없음 | LLM 키가 없거나 호출이 실패해도 화면이 깨지지 않는다 — 샘플 모드 배너로 알린다 |

## 시스템 아키텍처

```
[모바일 웹 web/] ──사진──▶ [FastAPI backend/]
                              │ ① redact.py   개인정보 가림
                              │ ② agent.py    판별 → 추출 → 근거 → 답장 판단
                              │      ├ extract.py  비전 LLM (좌표 포함)
                              │      └ rag.py      국가법령정보·정부24 (Chroma)
                              ▼
                        Decoded JSON ──▶ 화면: 3색 표시 · 할 일 카드 · 근거 링크
                              │
                              └─ 기한 ──▶ [n8n automation/] ──▶ D-3·D-day 알림 · 손주 모드 링크
```

## 데이터 모델

`backend/app/schema.py` 가 정본이다. 화면과 n8n 은 이 모양만 믿는다.

| 이름 | 필드 | 뜻 |
|---|---|---|
| `Mark` | `kind` · `text` · `value` · `bbox` | 원본 위 표시 하나. `kind` = `money`(빨강)·`deadline`(파랑)·`document`(초록), `bbox` = 사진 대비 비율 `[x, y, w, h]` |
| `Todo` | `title` · `due` · `amount` · `how` | 할 일 카드 한 장 |
| `Basis` | `claim` · `quote` · `law` | 풀이 문장 하나와 그 근거(원문 문장, 법령 조문) |
| `Decoded` | `doc_type` · `title` · `plain` · `marks` · `todos` · `basis` · `reply_needed` · `reply_draft` · `sample` | `/decode` 응답 전체. `sample = true` 면 샘플 모드 |
