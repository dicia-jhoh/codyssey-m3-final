## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 응답 시간 | 사진 1장 해독 15초 이내(처리 중 경과 초 표시 — 10초 넘으면 「조금만 더 기다려 주세요」). 실측 평균 3.9초·최대 9.8초(배포 서버, 합성 30장, 2026-11-01) |
| 정확도 | 테스트셋 30장에서 금액·기한·할 일 추출 90% 이상 — 실측 91.2%(93/102, 같은 조건) |
| 개인정보 | 사진은 메모리에서만 쓰고 저장하지 않는다. 추출 뒤 화면·공유 전 가림. 실물 고지서 사진은 저장소에 올리지 않는다 |
| AI 표시 | 모든 풀이 화면에 「AI 풀이 — 원문을 함께 확인하세요」 배지 |
| 접근성 | 큰 글씨(기본 18px 이상), 앱 설치 없이 링크 하나로 연다 |
| 키 없음 | LLM 키가 없거나 호출이 실패해도 화면이 깨지지 않는다 — 샘플 모드 배너로 알린다 |
| 업로드 한도 | 10MB 넘으면 본문을 다 받기 전에 413. 화면은 큰 사진을 미리 줄여 보낸다 |
| 요청 제한 | `/decode` IP 당 1분 10번(`DECODE_PER_MINUTE`) — 넘으면 429 + `Retry-After`(초), 화면은 「N초 뒤에 다시 올려 주세요」 |

## 시스템 아키텍처

```
[모바일 웹 web/] ──사진──▶ [FastAPI backend/]
                              │ agent.py    추출 → 개인정보 가림 → 근거 → 종류 판별 → 할 일 (과태료면 답장 초안)
                              │      ├ extract.py  비전 LLM Gemini (좌표 포함)
                              │      ├ redact.py   주민번호·계좌번호·전화번호 가림
                              │      ├ rag.py      법제처 조문 10개 (Chroma, 조문 번호로)
                              │      └ reply.py    과태료 의견 제출서 초안
                              │ notify.py   기한 사흘 전·당일 알림 일정 (alerts)
                              ▼
                        Decoded JSON ──▶ 화면: 3색 표시 · 할 일 카드 · 법 조문 원문 · 카카오톡 알림 미리보기 · 답장 초안
                              │                    │
                              │                    └─ [가족에게 보내기] ──▶ POST /share ──▶ SQLite 30일 ──▶ 손주 모드 링크
                              │                                              └─ 「다 했어요」 GET·PUT /share/{id}/done
                              └─ 기한(실제 해독, 지난 기한 제외) ──▶ [n8n automation/] 웹훅
```

## 데이터 모델

`backend/app/schema.py` 가 정본이다. 화면과 n8n 은 이 모양만 믿는다.

| 이름 | 필드 | 뜻 |
|---|---|---|
| `Mark` | `kind` · `text` · `value` · `bbox` | 원본 위 표시 하나. `kind` = `money`(빨강)·`deadline`(파랑)·`document`(초록), `bbox` = 사진 대비 비율 `[x, y, w, h]` |
| `Todo` | `title` · `due` · `amount` · `how` | 할 일 카드 한 장 |
| `Basis` | `claim` · `quote` · `law` | 풀이 문장 하나와 그 근거(원문 문장, 법령 조문) |
| `Alert` | `send_on` · `when` · `message` | 기한 알림 한 통(`when` = 사흘 전·당일), 카카오톡 모양 가상 발송 |
| `Decoded` | `doc_type` · `title` · `plain` · `marks` · `todos` · `basis` · `reply_needed` · `reply_draft` · `alerts` · `sample` · `ai_notice` | `/decode` 응답 전체. `doc_type` 에 `과태료` 가 있다. `sample = true` 면 샘플 모드, `ai_notice` = 화면 위 「AI 풀이 — 원문을 함께 확인하세요」 |
