# 또박또박 로고 사용 가이드

## 1. 로고
- **아이디어:** 빨간펜 첨삭처럼 펜이 「또」 한 글자를 한 바퀴 반 동그라미 친다. 공문에서 해야 할 일을 짚어 준다는 뜻이다.
- **버전**

| 버전 | 밝은 배경 | 어두운 배경 | 쓰는 곳 |
|---|---|---|---|
| 가로형(기본) | `ttobak-horizontal.svg` | `ttobak-horizontal-dark.svg` | 머리글·문서·발표 |
| 세로형 | `ttobak-stacked.svg` | `ttobak-stacked-dark.svg` | 포스터·표지·정사각 자리 |
| 심볼 | `ttobak-symbol.svg` | `ttobak-symbol-dark.svg` | 프로필·아바타 |
| 심볼 작은 컷 | `ttobak-symbol-small.svg` | — | 16~32px(동그라미·글자를 굵게 다시 그린 판) |
| 워드마크 | `ttobak-wordmark.svg` | — | 심볼이 이미 옆에 있을 때 |

- **한 색 판:** `lockups/ttobak-horizontal-{black,white,mono-8052ff}.svg`, `web/ttobak-symbol-{black,white,mono-8052ff}.svg`.
- **웹 아이콘:** `web/favicon.ico`·`favicon.svg`·`apple-touch-icon.png`·`icon-192/512.png`·`maskable-512.png`·`site.webmanifest`.

## 2. 여백
로고 둘레에 **「또」 획 두께의 2배** 만큼 비운다. 여백 크기는 로고 크기를 따라 커지고 작아진다.

## 3. 최소 크기
| 버전 | 화면 | 인쇄 |
|---|---|---|
| 가로형 | 너비 120px | 너비 30mm |
| 심볼 | 24px 이상은 `ttobak-symbol.svg`, 그보다 작으면 `ttobak-symbol-small.svg` 또는 `favicon` | 8mm |

## 4. 색
| 이름 | HEX | 쓰임 |
|---|---|---|
| 보라 Iris | `#8052FF` | 펜 동그라미, 앱 아이콘 바탕. 홈페이지의 채운 버튼과 같은 색 |
| 먹색 Ink | `#111111` | 밝은 배경 위 글자 |
| 흰색 | `#FFFFFF` | 어두운 배경 위 글자 |

- 허용하는 조합은 넷이다: 흰 바탕 + 컬러판, 검정 바탕 + 어두운 배경판, 보라 바탕 + 흰 한 색판(앱 아이콘), 흰 바탕 + 검정 한 색판.
- **로고에 빨강·파랑·초록을 쓰지 않는다.** 서비스에서 이 세 색은 각각 「낼 돈·기한·챙길 서류」를 뜻한다.

## 5. 글자
「또박또박」 글자는 폰트로 친 것이 아니다. 직선·직각으로 직접 그린 패스다. 문서·화면 본문은 Pretendard 로 쓴다.

## 6. 하지 말 것
- 늘이기·찌그러뜨리기, 회전, 그림자·외곽선·그라데이션 같은 효과를 넣지 않는다.
- 동그라미와 글자 사이 비율을 바꾸지 않는다.
- 펜 동그라미를 닫힌 원으로 고치지 않는다. 한 바퀴 반 겹침이 이 로고의 특징이다.
- 「또박또박」을 폰트로 다시 쳐서 대신 쓰지 않는다.
- 복잡한 사진 위에는 그대로 올리지 않는다. 앱 아이콘(보라 타일)판을 쓴다.

## 7. 출처

상표 검색은 하지 않았다. 대외적으로 쓰기 전에 키프리스 같은 상표 검색으로 확인한다.
